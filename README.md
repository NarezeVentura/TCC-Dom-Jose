Sistema de Vendas - Doces Caseiros

Este projeto é uma aplicação web simples para registrar vendas, calcular faturamento e lucro, e visualizar relatórios de forma organizada.

-Funcionalidades

- Cadastro de vendas
- Listagem de produtos
- Cadastro de vendedores
- Geração de relatórios diários, semanais e mensais
- Histórico de vendas e relatórios
- Interface web com navegação simples

-Tecnologias utilizadas

- Python
- Flask
- SQLite
- HTML, CSS e JavaScript

-Estrutura do projeto

- `app.py` — backend Flask e API
- `front end/` — arquivos da interface web
- `sistema_vendas.db` — banco de dados SQLite

-Como executar


2. Inicie o backend:
   ```bash
   python app.py
   ```

3. Acesse no navegador:
   ```text
   http://127.0.0.1:5000
   ```

-Observações

- O backend já serve a interface frontend automaticamente.
- O sistema utiliza SQLite para armazenar vendas, produtos, vendedores e relatórios.
